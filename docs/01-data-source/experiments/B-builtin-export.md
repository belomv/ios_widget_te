# Эксперимент B: встроенный экспорт календаря

- **Вариант:** [options.md → B](../options.md#b-встроенный-экспорт-календаря)
- **Статус:** 🟡 частично. iCal-ссылки нет. Есть интеграция с Google Calendar, её нужно проверить в UI
  на бесплатном аккаунте.
- **Дата:** 2026-09-25

## Гипотеза
В TE есть iCal-ссылка, экспорт в Google Calendar или ссылка «поделиться календарём», доступные на бесплатном тарифе.

## Шаги
1. Веб-версия `app.trainingendurance.com`: профиль → настройки → интеграции → календарь; меню «…» в календаре.
2. Мобильное приложение: то же самое.
3. Если ссылка нашлась — скачать `.ics`, проверить состав полей (название, описание, длительность, вид спорта) и глубину (на сколько недель вперёд).

## Результат (по коду веб-приложения, без входа)
- **iCal / .ics / webcal / публичной ссылки на календарь нет**: ни в JS-бандле, ни в GraphQL-схеме
  (разбор в [эксперименте A](A-private-web-api.md)).
- **Есть интеграция Google Calendar**: в списке провайдеров (Strava, Garmin, Suunto, Coros, Polar,
  Wahoo, Google Calendar, Intervals.icu) есть `GOOGLECALENDAR`. Текст в UI:
  «При включении все запланированные тренировки будут автоматически выгружаться в ваш Google Calendar».
  Подключается через OAuth Google (`providerConnect` → редирект).
- В клиентском коде эта интеграция ничем не ограничена по тарифу. Но ограничение может быть на сервере,
  это надо проверить руками.
- Попутно: интеграция **Intervals.icu** работает на *импорт* в TE (Zwift, MyWhoosh, Amazfit →
  Intervals → TE), для получения плана она не помогает.

## Как это можно использовать
TE → Google Calendar → календарь на iPhone (добавить Google-аккаунт в «Настройки → Календарь → Учётные
записи»). Дальше виджет читает события через **EventKit**, без сети и без токенов TE. Другой путь —
секретная iCal-ссылка Google Calendar («Закрытый адрес в формате iCal»).
Плюсы: официальный путь, авторизация TE не нужна. Минусы: в событии, скорее всего, только название,
время и описание (без структуры, вида спорта как поля, план/факт); задержка синхронизации Google.
