## Гипотеза
Календарь в `app.trainingendurance.com` загружается JSON-запросами с токеном, которые можно повторить
из кода. Токен живёт достаточно долго или обновляется без участия пользователя.

## Шаги (можно сделать самому в Chrome/Safari на компьютере)
1. Открыть `app.trainingendurance.com`, выйти из аккаунта.
2. DevTools (F12) → вкладка **Network** → включить **Preserve log**, фильтр **Fetch/XHR**.
3. Войти в аккаунт. Открыть календарь, переключить неделю или месяц вперёд и назад, открыть одну тренировку.
4. Правый клик по списку запросов → **Save all as HAR** → положить файл в `secrets/` (он в `.gitignore`)
   или выложить мне как удобно. ⚠️ В HAR будут пароль и токены. Если передаёшь мне файл — лучше
   потом сменить пароль, или сначала вручную удалить значения `password`, `Authorization`, `Cookie`.
5. Разбор (делаю я): эндпоинт входа, вид токена и его срок (`exp` в JWT), refresh, эндпоинт календаря,
   схема ответа, заголовки, CORS/анти-бот защита.
6. Прототип: `tools/te-probe` (скрипт), который по логину/паролю из `secrets/` печатает тренировки на 7 дней.

## Что записать в результат
- Базовый URL API, список нужных эндпоинтов (без токенов).
- Схема тренировки (поля).
- Способ входа и время жизни сессии.
