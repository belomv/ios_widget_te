# Виджет — идеи на потом

Не делаем сейчас, но не хотим потерять. Когда берём идею в работу — переносим в [DESIGN.md](DESIGN.md).

- **Поздравление с концом недели.** В воскресенье, если тренировка короткая (например, «60–70 км до 200 Вт
  спокойно»), внизу — весёлая иллюстрация и поздравление с завершённой неделей. Вариант: показывать только
  когда воскресная тренировка выполнена (`status: done`), тогда это награда, а не аванс. *(2026-09-26, владелец)*
- **Листать длинный комментарий** кнопкой в виджете (iOS 17, App Intents): стрелка «↓» показывает следующую
  порцию текста. Для комментариев, которые не влезают даже в 12 pt.
- **Тап по дню в полоске** показывает комментарий этого дня (тоже App Intents), без открытия приложения.
- **Medium как основной размер**, если короткие комментарии — норма, а Large — для тех, кому нужны полные тексты.
