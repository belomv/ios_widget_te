# Виджет — строки интерфейса

Все надписи виджета для String Catalog (`Localizable.xcstrings`). Язык — русский. Ключ = имя в коде.
`{…}` — подстановка. Дизайн и правила показа — [DESIGN.md](DESIGN.md).

**Статус:** утверждено владельцем 2026-09-26. Обращение к пользователю — на «ты».

## Заголовок дня (`FocusHeader`, справа капсом)

| Ключ | Текст | Когда |
|---|---|---|
| `focus.today` | Сегодня | раскрыт сегодняшний день |
| `focus.tomorrow` | Завтра · {день} | раскрыт завтрашний день (сегодня отдых). В Small — просто «Завтра» (`focus.tomorrow.short`) |
| `focus.tomorrow.short` | Завтра | Small |
| `focus.later` | {день} | раскрыт день через 2+ дня (например, сегодня вт отдых — показываем чт) |

`{день}` — короткое название дня недели (`weekday.*`), в заголовке капсом: «ЗАВТРА · ЧТ».

## Следующие тренировки (`UpcomingWorkout`, справа капсом)

| Ключ | Текст | Когда |
|---|---|---|
| `upcoming.next` | Дальше · {день} | блок «Дальше» в Large (одна следующая тренировка) |
| `upcoming.day` | {день} | тренировки недели в Extra large |

## Своя тренировка (загрузил спортсмен, без плана)

| Ключ | Текст | Когда |
|---|---|---|
| `own.subtitle` | Без плана тренера · загружено из {источник} | вместо комментария тренера. `{источник}` — первый из `uploaded_from`: Strava, Coros, Garmin… |

## Пустые состояния (`EmptyState`)

| Ключ | Текст |
|---|---|
| `empty.title` | Плана пока нет |
| `empty.text` | Тренер ещё не поставил тренировки на эту неделю |
| `signedOut.title` | Войди в аккаунт |
| `signedOut.text` | Открой приложение и войди в Training Endurance, чтобы видеть план |
| `signedOut.button` | Открыть приложение |

## Дни недели (`WeekStrip`, подписи в полоске)

`weekday.mon` … `weekday.sun`: пн, вт, ср, чт, пт, сб, вс. В заголовках — капсом (ПН…ВС) через стиль текста, не отдельными строками.

## Галерея виджетов (при добавлении на экран)

| Ключ | Текст | Где |
|---|---|---|
| `gallery.name` | Тренировки | название виджета в галерее (`configurationDisplayName`) |
| `gallery.description` | План недели и комментарий тренера | описание (`description`) |

## Не строки, а данные — показываем как есть

Название тренировки, комментарий тренера, заголовок и текст заметки тренера (`event`) — из TE без изменений,
с опечатками. Пустые строки в комментарии схлопываем, длинное обрезаем «…» (делает система).

## Решения

- Обращение — на «ты» (как пишет тренер).
- Две тренировки в день: у первой — «Сегодня», у второй подписи нет (без «утро / вечер», без «1 из 2»).
- Строки «Обновлено в …» / «нет сети» нет: показываем последние загруженные данные молча.
- Название виджета в галерее — «Тренировки».
