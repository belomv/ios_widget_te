# Виджет — пройденные разведки

Новые записи сверху. Что пробовали, что выбрали и почему. Текущий итог — в [DESIGN.md](DESIGN.md).

## 2026-09-26 — Визуальный стиль (в работе)

Решили сначала довести до финального вида одну карточку (Large B, суббота), а уже потом рисовать остальные
состояния и размеры: от стиля могут зависеть правки раскладки.

Цвета спорта: бег `#FF375F` (розово-красный), вело `#0A84FF` (синий). Выполнено — кружок залит цветом спорта,
впереди — контур цветом спорта. «Сегодня» и линия-цитата — цветом спорта раскрытой тренировки.

| Стиль | Суть | Решение |
|---|---|---|
| 1. Светлый системный | белый фон, цвет только в статусах и акцентах | ✅ светлая тема |
| 2. Тёмный | то же на `#1C1C1E` — по сути тёмная тема стиля 1 | ✅ тёмная тема |
| 3. Цвет по спорту | фон — градиент цвета спорта раскрытого дня, всё белое | ❌ в тонированном и прозрачном режимах iOS фон заменяется стеклом — главная черта стиля пропадает; длинный текст на цвете читается хуже |

## 2026-09-26 — Доп. информация под коротким комментарием

Сделали карточки Large B для четырёх сценариев: сегодня вт, ср (отдых → показываем чт), сб, вс.
**Увидели:** вариант B рассчитан на длинный комментарий, а обычно он короткий (1–4 строки) —
в 3 из 4 карточек пустует половина виджета.

Варианты заполнения:
1. Следующая тренировка — ✅ берём, 2-й приоритет.
2. Заметка тренера за день — ✅ берём, 1-й приоритет (решение владельца). Сначала поставили над комментарием,
   перенесли **под** него: сначала читается главное — тренировка.
3. Крупнее шрифт для короткого текста — ❌ одна строка всё равно висит на пустом фоне.
4. Сделать основным Medium — ⏸ вернуться, когда начнём Medium.

Во вторник заметка + следующая тренировка не влезли (не хватило 16 pt) → следующую убрали, как и положено по приоритету.

Воскресенье: «дальше» некуда — понедельник выходной. Вместо следующей тренировки — поздравление с концом
недели и иллюстрация (решение владельца).

## 2026-09-26 — Как вместить больше текста (A → B)

В варианте A комментарий обрезался на 8 строках, субботний (13 строк) не влезал. Нашли место:

| Приём | Выигрыш | Решение |
|---|---|---|
| Убрать строку «Неделя 21–27 сен» и «1 из 4» | ~1,5 строки | ✅ в B |
| Убрать подпись «ТРЕНЕР», вместо неё линия-цитата | ~1 строка | ✅ в B |
| «Завтра · сб» в строку заголовка | ~1 строка | ✅ в B |
| Шрифт 14 → 13 pt, автоподгонка до 12 pt | ~1–2 строки | ✅ в B |
| Склеивать короткие строки через « · » | 1–3 строки | ❌ ломает структуру плана (пункты столбиком) |
| Листать комментарий кнопкой (iOS 17 App Intents) | весь текст | ⏸ запасной вариант для совсем длинных |

Итог: субботний комментарий влезает целиком. Цена — меньше «воздуха», пропал счётчик недели.
Выбран **B**.

## 2026-09-25 — Полоска недели

- Сначала в кружке было число, под ним подпись «бег»/«вело». → Число убрали, в кружок поставили иконку спорта,
  подпись убрали: полоска ниже на 8 pt, комментарию +2 строки. Дату и так понятно по дню недели.
- Отдых был пустым серым кружком — терялся рядом с тренировками. → Маленькая точка.
- Пропуск: пунктир → красный пунктир + «×» (перегружено) → **жёлтый** залитый кружок + «×», без пунктира.
- Строку «Бег · впереди» под заголовком убрали: вид спорта видно по иконке, статус — по полоске.

## 2026-09-25 — Раскладка Large

Данные: неделя 21–27.09 ([examples](examples/README.md)). Заголовки 1–3 слова, комментарии до ~12 строк —
семь дней с полными комментариями в Large не влезают. Значит: неделя компактно + один день подробно.

| Вариант | Суть | Решение |
|---|---|---|
| A. Фокус дня + полоска недели | полоска 7 дней сверху, ниже раскрытый день с комментарием | ✅ выбран |
| B. Список недели | строка на тренировку + превью комментария | ❌ комментарий почти не влезает, на неделе из 6–7 тренировок не влезут даже заголовки |
| C. Две колонки | слева список, справа детали | ❌ на iPhone ~338 pt ширины — русский текст рвётся |
