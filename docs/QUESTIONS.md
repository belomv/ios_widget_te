# Открытые вопросы

Отвечай прямо здесь или в чате, я перенесу ответы.

1. **Что показывать в виджете?** Только план (что сегодня/завтра), или ещё выполненное и сравнение
   план/факт? Нужны ли поля вроде TSS/нагрузки, зон, калорий, питания?
2. **Как ты заходишь в TE?** Email + пароль, Google, Apple? От этого зависит, насколько легко
   авторизоваться из кода.
3. **Есть ли в настройках TE** что-то вроде «Экспорт», «Календарь», «Подписка», «iCal», «Google Calendar»,
   «Поделиться календарём», «API», «Интеграции»? Пришли скриншоты, если не трудно.
4. **Какие интеграции у тебя подключены?** Особенно Garmin Connect и Apple Watch: уходят ли плановые
   тренировки из TE на часы?
5. **Свой сервер допустим?** Например, бесплатный Cloudflare Worker или GitHub Actions по расписанию,
   которые хранят твои учётные данные TE. Или всё должно работать только на телефоне?
6. **Сетевой доступ для меня.** Можно добавить `trainingendurance.com` и `app.trainingendurance.com`
   в разрешённые домены окружения (облачное окружение → Edit → Network access)? Тогда разведку API
   сделаю сам. Если нет — снимешь HAR по инструкции.
7. **Есть ли Mac с Xcode** для сборки приложения? Какая версия iOS на телефоне?
